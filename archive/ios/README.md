# Archived iOS App

This directory contains the original native Swift/SwiftUI CalSnap app. It is preserved as
historical source material and is not under active development or release planning.

The active product is the web PWA in [`../../calsnap-web/`](../../calsnap-web/). The iOS
implementation, technical specification, engineering rules, and PR records under this
directory describe an earlier product and platform model. They are not current requirements
for the web app.

The archived project may require its original Xcode and dependency environment to build.
No current CI job validates it, and changes should not be made here unless the iOS app is
explicitly revived.
